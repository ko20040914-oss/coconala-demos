# 予約・申込フォームの転記通知をGASで自動化します

Coconala出品（3,000円、教室・サロン向け）のデモパッケージです。
体験レッスンの申込を「受付台帳」に1行追加し、店舗オーナーへの通知と申込者への受付確認メールを送る仕組みです。受付は予約確定を意味しません。

名前・日時・メールなどはすべて架空の見本です。メールは予約ドメイン `example.com` を使用しています。実在する個人情報や実在アドレスは含めていません。

## ファイル

- `gas/Code.gs`：Google Apps Script（GAS）のコード。
- `data/sample_applications.csv`：架空の申込10件。
- `tools/generate_sample_xlsx.py`：CSVからExcel見本を生成するPythonスクリプト。
- `sample/受付台帳サンプル.xlsx`：処理後の台帳を再現した見本（10件）。「送信済み」は表示の再現であり、実際には送信していません。

## 設定手順

1. **Googleフォームを作ります。** Googleフォームで「空白のフォーム」を選び、タイトルを「体験レッスン申込フォーム」にします。質問名を正確に「名前」「希望日時」「コース」「連絡先メール」にしてください。名前・希望日時・連絡先メールは「記述式」、コースは「プルダウン」（例：ヨガ体験、アロマ体験、ピアノ体験）にします。希望日時の説明に「例：2026/11/10 14:00」と書きます。4項目とも「必須」をオンにし、連絡先メールは「回答の検証」でメールアドレス形式を指定します。「メールアドレスを収集する」機能だけで質問を代用せず、上記の質問を作ってください。

2. **回答用スプレッドシートを作ります。** フォームの「回答」タブから緑色のスプレッドシートアイコンを押し、「新しいスプレッドシートを作成」を選びます。作成された「フォームの回答 1」はそのまま残してください。ここが元の回答記録です。

3. **受付台帳を作ります。** 同じスプレッドシートの左下の「＋」で別タブを追加し、名前を「受付台帳」にします。1行目のA1からF1に順に「受付日時」「名前」「希望日時」「コース」「連絡先メール」「ステータス」を入力します。空のタブでもコードがヘッダーを作ります。元の回答タブを「受付台帳」に変更しないでください。

4. **GASを貼り付けます。** スプレッドシートの「拡張機能」→「Apps Script」を開き、最初のコードを削除して `gas/Code.gs` の全内容を貼り付け、保存します。プロジェクト名は「体験レッスン受付自動化」などにします。プロジェクトの設定でタイムゾーンを「東京（Asia/Tokyo）」にし、スプレッドシートも「ファイル」→「設定」で日本時間にします。

5. **上部のCONFIGを設定します。** `SPREADSHEET_ID` の `REPLACE_WITH_YOUR_SPREADSHEET_ID` を、スプレッドシートURLの `/d/` と `/edit` の間の文字列に置き換えます。`SHEET_NAME` は「受付台帳」のままで構いません。`OWNER_EMAIL` の `owner@example.com` はダミーです。メールを利用するときに、ご自身が管理する通知先へ置き換えてください。初回は `SEND_EMAILS: false` のままにします。これで台帳だけを確認できます。実際の設定を公開リポジトリへ書き戻さないでください。

6. **トリガーを1個設定します。** Apps Script左側の時計アイコン「トリガー」→「トリガーを追加」を押し、実行する関数を `onFormSubmit`、デプロイを「Head」、イベントのソースを「スプレッドシートから」、イベントの種類を「フォーム送信時」にします。保存し、表示されるGoogleの権限確認は内容を確認したうえで、ご自身のプロジェクトに許可します。同じトリガーを重複登録しないでください。フォーム側のトリガーは使用しません。エディタの「実行」ボタンで `onFormSubmit` を実行するとイベントがないためエラーになります。

7. **ダミーでテスト送信します。** フォームをプレビューし、CSVの1件目などのダミー情報を入力して「送信」します。元の回答タブと「受付台帳」に各1件が記録され、台帳のステータスに「未送信：デモモード」が出ることを確認します。フォームの公開・回答受付の設定が求められる場合は、まずテスト担当者だけが回答できる範囲にしてください。CSVをシートに貼り付けたり、Excelを開いたりするだけではトリガーは動きません。

8. **必要な場合だけメールの動作を確認します。** ご自身の非公開GASで `OWNER_EMAIL` とテスト申込の連絡先を、ご自身が受信できる実際のアドレスにし、`SEND_EMAILS: true` に変更して保存します。フォームから新しく1件送信し、通知メール・確認メールと台帳の「送信済み」を確認します。`example.com`・`example.net`・`example.org` 宛ては安全のためコードが送信を止めます。テスト後は `false` に戻すか、確認済みの設定で運用してください。このパッケージの作成・検証では、Googleへの送信やメール送信を行っていません。

## 入力漏れ・送信失敗への対応

必須項目が欠けても受付台帳への追加を続け、ステータスに「注意」を残します。メールが未入力・形式不正の場合は確認メールを送らず記録します。他の項目に不足があっても、有効なメールには不足項目を含む受付確認を送ります。オーナー通知と確認メールの送信はそれぞれ失敗を捕捉し、片方の失敗で他方を止めません。

権限や送信上限によるメール失敗は台帳に残ります。GASの「実行数」と台帳を確認し、連絡が必要なら手動で対応してください。送信済みはMailAppが送信要求を受け付けた意味で、到着保証ではありません。スプレッドシートID・ヘッダー不正やサービス障害では転記できないことがあるため、元の回答タブも確認します。自動再送・重複排除はありません。トリガーの重複や再実行で二重受付・二重送信になる可能性があるので、実行前に台帳を確認してください。

## 個人情報の扱い

本番では利用目的と保管期間を決め、フォームに案内を掲載してください。フォーム・回答・台帳・メールには個人情報が含まれるため、共有先は必要な担当者に限定します。公開リンクや公開GitHubへ本番データ・アドレス・設定を載せないでください。不要な回答・台帳・メールは決めた期間で削除します。CSVのダミーを本番用に置き換える場合も、非公開のご自身の環境でのみ行い、公開デモには戻さないでください。

## Excel見本の再生成

Python 3とopenpyxlが必要です。リポジトリのフォルダーで次を実行します。

```sh
python -m pip install openpyxl
python tools/generate_sample_xlsx.py
```

生成先は `sample/受付台帳サンプル.xlsx` です。既存の同名見本は上書きされます。受付日時は日本時間を想定した固定の架空日時です。保存後に実ファイルを開き直して、6列のヘッダー・全11行（見出し1行＋データ10行）・全件の処理済み表示を検証します。Google接続やメール送信はしません。
